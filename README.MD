# Louis Boddie — Technical Portfolio

Python builder focused on local-first systems, offline-first tools, Linux dashboards, automation, and AI-assisted desktop infrastructure.

My work centers around practical software for operators: clear state, local data, CLI control, restrained interfaces, and systems that can keep working without depending on the cloud.

---

## Core Projects

### 1. O.B.E.O.S. — Official Blackfong Environment Operating System

**Local-first command environment for Linux automation, desktop control, and AI-assisted system orchestration.**

OBEOS is the flagship project: a command OS above the kernel where a long-running engine acts as the authority, and clients such as CLI tools, desktop panels, and scripts connect to issue intent and observe outcomes.

**Focus areas:**

- Python systems architecture
- Linux-first design
- CLI control
- SQLite state storage
- Local automation
- Modular service architecture
- Future AI assistant integration

---

### 2. Nightwatch OS — Operations Dashboard

**Local-first dashboard for shift logging, task tracking, focus mode, and system status.**

Nightwatch OS is a practical operator dashboard built for overnight work, system awareness, and clean task management. It favors calm design, local storage, and reliable state over unnecessary decoration.

**Focus areas:**

- FastAPI
- SQLite
- Shift logging
- Task ledger
- System monitoring
- CLI companion
- Linux/Raspberry Pi workflows

---

### 3. QuietDrop — File Intake Automation

**Local-first file intake and staging utility for reviewing, tagging, renaming, and archiving dropped files.**

QuietDrop watches local folders, detects incoming files, and gives the user control over what happens next. It is designed as a simple but expandable automation tool for local file workflows.

**Focus areas:**

- Python CLI tooling
- Local file automation
- Folder watching
- TOML configuration
- Review/archive workflow
- Web UI and JSON API direction

---

### 4. Blackfong Installer — Deployment Tooling

**Installer and deployment path for Blackfong/OBEOS systems.**

Blackfong Installer supports the larger goal of making the ecosystem installable, portable, and usable across Linux-first machines and future dedicated hardware.

**Focus areas:**

- System setup
- Linux deployment
- Offline-first installation flow
- Future USB/ISO installer direction
